Ардагани — перенос сайта на свой хостинг

Это готовый статический сайт: HTML, CSS, JavaScript и изображения.
Сборка, Node.js, база данных и серверное приложение не нужны.
Все файлы сайта входят в архив. Файл index.html должен лежать в корне сайта,
а папка assets — рядом с ним. Сохраните структуру папок.

ОБЫЧНЫЙ ХОСТИНГ
1. Создайте сайт или поддомен в панели хостинга.
2. Откройте файловый менеджер и папку этого сайта (часто public_html).
3. Загрузите туда архив и распакуйте его. index.html должен оказаться
   непосредственно в папке сайта, а не в дополнительной вложенной папке.
4. Подключите домен к хостингу и включите HTTPS в его панели.
5. Откройте сайт и проверьте поиск, выбор блюд, фотографии и валюты.

СВОЙ СЕРВЕР (UBUNTU / DEBIAN + NGINX)
1. Установите Nginx, если он ещё не установлен:
   sudo apt update
   sudo apt install nginx unzip
2. Загрузите архив на сервер по SFTP либо через scp:
   scp ardagani-site.zip USER@SERVER_IP:/tmp/
   Замените USER и SERVER_IP своими данными.
3. Подготовьте отдельную папку и распакуйте архив:
   sudo mkdir -p /var/www/ardagani
   sudo unzip /tmp/ardagani-site.zip -d /var/www/ardagani
   sudo find /var/www/ardagani -type d -exec chmod 755 {} +
   sudo find /var/www/ardagani -type f -exec chmod 644 {} +
4. Создайте /etc/nginx/sites-available/ardagani со следующим содержимым:

   server {
       listen 80;
       server_name menu.example.com;
       root /var/www/ardagani;
       index index.html;

       location / {
           try_files $uri $uri/ =404;
       }
   }

   Замените menu.example.com вашим доменом.
   Этот блок добавляет отдельный сайт. Не заменяйте им конфиги других сайтов.
5. Включите конфиг, проверьте его и перезагрузите Nginx:
   sudo ln -s /etc/nginx/sites-available/ardagani /etc/nginx/sites-enabled/ardagani
   sudo nginx -t
   sudo systemctl reload nginx
6. В DNS домена направьте A-запись на IP сервера.
   Разрешите входящие соединения на порты 80 и 443 в настройках сервера.
7. Настройте HTTPS средствами своего хостинга или сертификатом Let's Encrypt.

ЛОКАЛЬНЫЙ ПРОСМОТР
Распакуйте архив и запустите в этой папке:
   python3 -m http.server 8080
Откройте http://localhost:8080 в браузере.

ЧТО РЕДАКТИРОВАТЬ
menu.js — названия, цены и состав блюд.
app.js — название ресторана, адрес, подписи и отображение меню.
style.css — оформление.
assets/ — фотографии и декоративные изображения.
currency.js — пересчёт валют.

ОСОБЕННОСТИ
Пересчёт валют запрашивает внешний источник курсов через HTTPS.
При недоступности источника может использоваться недавний сохранённый курс;
если курс устарел, эквиваленты скрываются. Цены в лари работают независимо.
При настройке собственного Content-Security-Policy разрешите connect-src
для https://cdn.jsdelivr.net, чтобы загрузка курсов работала.
Выбранные блюда, язык и валюта хранятся в браузере посетителя (localStorage).
При переходе на другой домен прежний список автоматически не переносится.
Кнопка «Показать официанту» показывает список на экране и не отправляет заказ.
Изображения блюд сгенерированы для примера.

Архив не содержит Git-историю, служебные настройки Sites или учётные данные.
Сайт полностью работает без хостинга ChatGPT Sites.
